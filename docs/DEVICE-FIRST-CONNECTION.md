# 首次设备接入

2026-11-17，已实现。工作树位于 `.claude/worktrees/wp-device-first-credential`，分支 `wp/device-first-credential`，负责人 Codex，审查后经确认清理。

设备登记成功后，页面使用独立的凭据接口自动为普通直连设备签发首份凭据。未选模板默认使用内置 MQTT 直连与访问令牌，选中普通 MQTT 直连模板时默认签发由平台管理的令牌。登记结果页显示可复制的登录信息、下发状态和已知的接入地址。两个请求分别授权，签发失败保留设备并用相同请求编号重试，避免重复建档或发放多份凭据。凭据更换和撤销保留在设备连接页。
